# Student Result Analyzer

## Problem Statement

Managing and analyzing student examination results manually can be time-consuming and may lead to calculation errors. Calculating total marks, percentage, grade, and pass/fail status for multiple students also requires additional effort.

The Student Result Analyzer provides a simple Java-based solution for managing student information, calculating individual results, and performing basic class-level analysis.

## Scope

The project focuses on basic student result management through a command-line interface.

The system allows users to:
- Add student details and marks.
- View stored student records.
- Search for a student using their ID.
- Calculate total marks and percentage.
- Determine grade and pass/fail status.
- Calculate class average.
- Identify the class topper.

## Target Users

The system is intended for:
- Students learning Java programming.
- Teachers or instructors requiring a simple result-analysis tool.
- Users who need basic student result calculations.

## High-Level Features

1. Student Management
2. Result Calculation
3. Student Result Display
4. Class Performance Analysis
